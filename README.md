# YOLOv5 目标检测软件

这是一个基于YOLOv5的目标检测软件，使用Python和Tkinter开发，支持多种模型格式和检测功能。

## 功能特性

- **模型格式支持**：支持.pt、.onnx格式的YOLOv5模型
- **检测功能**：
  - 图片检测
  - 摄像头实时检测
  - 视频检测
- **实时显示**：实时显示原图和检测结果
- **检测信息**：显示检测到的目标类别、置信度和位置信息
- **界面友好**：直观的图形用户界面

## 安装方法

1. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```

2. 运行软件：
   ```bash
   python yolo_detector.py
   ```

## 使用方法

1. **加载模型**：
   - 点击"选择模型"按钮选择模型文件
   - 从下拉菜单中选择模型格式（pt/pth/onnx）
   - 点击"加载模型"按钮加载模型

2. **图片检测**：
   - 选择并加载模型
   - 点击"图片检测"按钮
   - 选择要检测的图片文件
   - 软件会显示原图和检测结果

3. **摄像头检测**：
   - 选择并加载模型
   - 点击"摄像头检测"按钮开始实时检测
   - 点击"停止检测"按钮停止检测

4. **视频检测**：
   - 选择并加载模型
   - 点击"视频检测"按钮
   - 选择要检测的视频文件
   - 软件会实时处理视频并显示结果
   - 点击"停止检测"按钮停止检测



## 开发

此软件使用YOLOv5模型进行目标检测，通过ultralytics库加载和使用模型。界面使用Tkinter构建，图像处理使用OpenCV和Pillow库。
